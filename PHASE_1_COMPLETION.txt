## 🎓 Developer Notes

### How to Use Shared Components
```jsx
// Import from shared index
import { Button, Input, Card } from '../components/shared';

// Use in your components
<Button variant="primary">Save</Button>
<Input type="email" label="Email" />
<Card>Content</Card>
```

### Adding New Components
1. Create ComponentName.jsx in `src/components/shared/`
2. Create ComponentName.module.css for styling
3. Add export to `src/components/shared/index.js`
4. Use design tokens from `src/styles/globals.css`

### Accessing Design Tokens in JS
```jsx
import { designSystem } from '../styles/designSystem';

const primaryColor = designSystem.colors.primary[500];
const spacing = designSystem.spacing[4];
```

### Using Design Variables in CSS
```css
.myClass {
  color: var(--primary-500);
  padding: var(--spacing-4);
  border-radius: var(--radius-md);
  box-shadow: var(--shadow-md);
  font-family: var(--font-body);
}
```
