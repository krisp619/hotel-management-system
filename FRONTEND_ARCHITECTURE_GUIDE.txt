## API Structure

### auth.js
```javascript
export const authAPI = {
  login: (email, password) => POST /auth/login,
  register: (userData) => POST /auth/register,
  logout: () => POST /auth/logout,
  refreshToken: () => POST /auth/refresh,
  updateProfile: (userId, data) => PUT /users/{id},
}
```

### hotels.js
```javascript
export const hotelsAPI = {
  search: (filters) => GET /hotels?location=&checkIn=&checkOut=,
  getById: (id) => GET /hotels/{id},
  getReviews: (id) => GET /hotels/{id}/reviews,
  getRooms: (id) => GET /hotels/{id}/rooms,
  getAmenities: (id) => GET /hotels/{id}/amenities,
}
```

### bookings.js
```javascript
export const bookingsAPI = {
  create: (data) => POST /bookings,
  getAll: (userId) => GET /bookings?userId=,
  getById: (id) => GET /bookings/{id},
  cancel: (id) => DELETE /bookings/{id},
  update: (id, data) => PUT /bookings/{id},
}
```

## Hooks Implementation

```javascript
// useAuth.js - Authentication
const useAuth = () => {
  const { user, login, register, logout, loading, error }
  return { user, login, register, logout, loading, error }
}

// useBooking.js - Booking state
const useBooking = () => {
  const { booking, setBooking, confirmBooking, cancelBooking }
  return { booking, setBooking, confirmBooking, cancelBooking }

// useFetch.js - API calls
const useFetch = (url, options) => {
  const { data, loading, error, refetch }
  return { data, loading, error, refetch }

// useForm.js - Form handling
const useForm = (initialState, onSubmit) => {
  const { values, errors, touched, handleChange, handleSubmit }
  return { values, errors, touched, handleChange, handleSubmit }
}

// useDebounce.js - Debouncing
const useDebounce = (value, delay) => {
  const debouncedValue = ...

// useLocalStorage.js - Persistence
const useLocalStorage = (key, initialValue) => {

  return [value, setValue]
}
```

## Routing Structure

```jsx
// App.jsx
<BrowserRouter>
  <Routes>
    {/* Public Routes */}
    <Route path="/" element={<Home />} />
    <Route path="/hotels" element={<HotelListing />} />
    <Route path="/hotels/:id" element={<HotelDetails />} />
    <Route path="/login" element={<Login />} />
    <Route path="/register" element={<Register />} />
    
    {/* Protected Routes */}
    <Route element={<ProtectedRoute />}>
      <Route path="/checkout" element={<Checkout />} />
      <Route path="/confirmation/:id" element={<Confirmation />} />
      <Route path="/dashboard" element={<Dashboard />} />
      <Route path="/bookings" element={<Bookings />} />
      <Route path="/profile" element={<Profile />} />
      <Route path="/settings" element={<Settings />} />
    </Route>

    {/* Admin Routes */}
    <Route element={<AdminRoute />}>
      <Route path="/admin" element={<AdminDashboard />} />
      <Route path="/admin/hotels" element={<HotelsAdmin />} />
      <Route path="/admin/rooms" element={<RoomsAdmin />} />
      <Route path="/admin/bookings" element={<BookingsAdmin />} />
      <Route path="/admin/users" element={<UsersAdmin />} />
    </Route>

    {/* Error Routes */}
    <Route path="/404" element={<NotFound />} />
    <Route path="/500" element={<ServerError />} />
    <Route path="*" element={<Navigate to="/404" />} />
  </Routes>
</BrowserRouter>
```

## Performance Optimization

1. **Code Splitting**
   - Lazy load pages with React.lazy()
   - Separate admin and public bundles

2. **Image Optimization**
   - Use WebP format with fallbacks
   - Lazy load images with Intersection Observer
   - Compress images before upload

3. **API Optimization**
   - Cache API responses
   - Debounce search inputs
   - Pagination for lists
   - Request cancellation on unmount

4. **Bundle Optimization**
   - Tree shaking unused code
   - Minify CSS/JS
   - Compress assets
   - Use CDN for static files

## Development Workflow

1. **Feature Development**
   - Create feature branch
   - Develop components
   - Test functionality
   - Submit PR for review

2. **Code Quality**
   - ESLint for code style
   - Prettier for formatting
   - Husky for git hooks
   - Pre-commit tests

3. **Deployment**
   - Build optimized bundle
   - Run tests before deploy
   - Deploy to staging
   - Run E2E tests
   - Deploy to production

This architecture ensures:
- **Scalability** - Easy to add new features
- **Maintainability** - Clear folder structure
- **Reusability** - Component composition
- **Performance** - Optimized loading
- **Accessibility** - WCAG compliance
- **Mobile-first** - Responsive design
