## Performance Tips

1. **Images**
   - Use WebP with JPEG fallback
   - Lazy load with loading="lazy"
   - Compress before upload
   - Use responsive images

2. **Code**
   - Lazy load pages with React.lazy()
   - Debounce search input (300ms)
   - Cancel requests on unmount
   - Use React.memo for pure components

3. **Assets**
   - Minify CSS/JS
   - Remove unused CSS
   - Compress fonts
   - Use CDN for static files

4. **Bundle**
   - Tree shake unused code
   - Split code by route
   - Cache busting with hashes
   - Gzip compression

## Common Issues & Solutions

**Issue: Styles not applying**
→ Check CSS module import syntax: `import styles from './Component.module.css'`
→ Use: `className={styles.className}`

**Issue: Colors look different**
→ CSS variables defined in: `src/styles/globals.css`
→ Import fonts in: `index.html` or `main.jsx`

**Issue: Mobile layout broken**
→ Use: `@media (min-width: 640px)` for tablet+
→ Default (no media query) = mobile styles

**Issue: Form validation not working**
→ Check input `required` attribute
→ Verify regex patterns
→ Test onChange handler

**Issue: Animations jumpy**
→ Use `animation-timing-function: ease-in-out`
→ Avoid micro animations on low-end devices
→ Test with devtools throttling
