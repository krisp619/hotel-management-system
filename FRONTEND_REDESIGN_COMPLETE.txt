### 7. Frontend Architecture ✓

**Folder Structure**
```
src/
├── components/
│   ├── common/         (shared layout)
│   ├── shared/         (UI primitives)
│   ├── search/         (search features)
│   ├── hotels/         (hotel display)
│   ├── booking/        (booking flow)
│   └── auth/           (auth features)
├── pages/              (page components)
├── hooks/              (custom hooks)
├── context/            (state management)
├── api/                (API calls)
├── styles/             (global styles)
├── utils/              (helper functions)
└── config/             (app configuration)
```

**State Management**
- AuthContext (user, login, logout)

- ThemeContext (dark mode, themes)

## Design Decisions & Why

### Colors
- **Blue Primary**: Trust (users share payment info)
- **Orange Secondary**: Urgency (limited availability)
- **Green Accent**: Confirmation (safe to proceed)
- **Red Error**: Danger (avoid actions)
- **Gray Scale**: Hierarchy (visual structure)

### Typography
- **Poppins Headings**: Friendly, modern, travel-friendly
- **Inter Body**: Highly readable, works at all sizes
- **JetBrains Mono Code**: Precision, data display

### Spacing
- **8px Base**: Mathematical precision, consistency
- **Generous Padding**: Professional, not cramped
- **Clear Breathing Room**: Modern, luxury feel

### Animations
- **250ms Base Speed**: Feels responsive, not instantaneous
- **Smooth Transitions**: Professional, not jarring
- **Subtle Effects**: Enhance without distracting

### Responsive
- **Mobile First**: Progressive enhancement
- **Flexible Layouts**: Adapts to all screens
- **Touch Friendly**: 44px+ tap targets
- **Performance**: Smaller bundles on mobile

## Questions & Answers

**Q: Can I customize the colors?**  
A: Yes, edit CSS variables in `src/styles/globals.css` or use theme context.

**Q: How do I add new components?**  
A: Follow the pattern in `components/` folder with `.jsx` file and `.module.css` file.

**Q: Is dark mode supported?**  
A: Yes, media query `prefers-color-scheme: dark` is implemented.

**Q: Can I use Tailwind instead?**  
A: Yes, you can replace CSS modules with Tailwind classes (requires setup).

**Q: How do I maintain mobile responsiveness?**  
A: Use mobile-first CSS with `@media (min-width: 640px)` breakpoints.
