### Color Psychology
- **Primary Blue (#3b82f6):** Trust, travel industry standard (MakeMyTrip, Booking.com)
- **Accent Orange (#ea580c):** Energy, adventure, adventure travel appeal
- **Green/Gold:** Positive actions, ratings, confirmations

### Typography
- **Poppins:** Modern, friendly, personality (headings)

- **Scale:** Large headlines (up to 60px) for attention

### Spacing
- **8px grid:** Professional consistency across app

### Animations
- **Smooth transitions:** 200ms base timing

- **Forms:** Clear labels, helpful placeholder text
- **Icons:** Emoji for simplicity and universal appeal

## 🎓 Usage Guide

### Starting Dev Server
```bash
cd frontend-react
npm run dev
# Opens at http://localhost:3000
```

### Building for Production
```bash
npm run build
# Creates optimized dist/ folder
```

### Adding New Pages
1. Create `src/pages/PageName.jsx`
2. Create `src/pages/PageName.module.css`
3. Add route to `src/App.jsx`
4. Use CSS variables for styling
5. Import shared components from `src/components/shared`

### Using Design System
```jsx
// In CSS
color: var(--color-primary-600);
padding: var(--spacing-4);
box-shadow: var(--shadow-md);

// In JSX - use design tokens directly in inline styles if needed
<div style={{ color: 'var(--color-primary-600)' }}>
```
